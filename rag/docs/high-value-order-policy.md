# High Value COD Order Policy

## Threshold
A high-value COD order is any COD order with order value above ₹3,000.

## Handling
High-value COD orders that are also MEDIUM or HIGH risk require a human agent call-back for verification, not just WhatsApp or IVR. The agent confirms the order, the delivery address, and the customer's availability.

## Courier selection
High-value COD orders should preferably be shipped with Bluedart, which has the lowest RTO rate among our partners, provided the pincode is serviceable.
