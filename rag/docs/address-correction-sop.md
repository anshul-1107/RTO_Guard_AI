# Address Correction SOP

## Incomplete addresses
An address is considered incomplete if it has no house or flat number, or no landmark, or is shorter than 25 characters. Incomplete addresses are a major cause of failed deliveries and RTO.

## Correction request
For COD orders with an incomplete address, the verification message must also ask the customer to share their house number and a nearby landmark. The customer can reply on WhatsApp; the reply is added to the order before dispatch.

## Pincode checks
If the pincode is not serviceable by any courier partner, the order is cancelled with reason code ADDR_UNSERVICEABLE and the customer is informed. If the pincode is serviceable only for prepaid, the customer is offered prepaid conversion.

## Timeline
Address correction must be completed within the 24-hour hold window.
