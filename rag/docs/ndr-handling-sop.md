# NDR Handling SOP

## Goal
Most RTOs start as an NDR. Acting on every NDR quickly is the last chance to save the order.

## Actions on NDR
When an NDR is received, contact the customer on WhatsApp within 2 hours to confirm availability and address. If the customer confirms, request a reattempt with the courier. If the customer refuses, mark the order for RTO immediately to save reattempt charges.

## Refusal at doorstep
If the NDR reason is "customer refused", do not request a reattempt unless the customer explicitly asks for one in writing.
